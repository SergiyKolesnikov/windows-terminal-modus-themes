= Modus Color Schemes for Windows Terminal

This is a port of https://protesilaos.com/emacs/modus-themes[the Emacs' Modus themes by Protesilaos Stavrou] to Windows Terminal.

Modus themes are great for coding because they are built around accessibility and clarity first:

. High contrast improves readability and reduces eye strain during long coding sessions.
. Consistent color semantics make syntax, diffs, and UI states easier to parse quickly.
. They include variants (light/dark, tinted, color-vision-optimized) so you can pick what stays comfortable and legible for your eyes.

== Installation ==

. In Windows Terminal, open Settings and click "Open JSON file". This will open `settings.json` in your default text editor.
. Copy the content of the desired scheme JSON file(s) into the `"schemes"` array in `settings.json`. If the array already contains other schemes, separate each entry with a comma. Save the file.
. In the `"profiles"` section, set `"colorScheme"` to the name of the scheme for each profile you want to apply it to.

== Updating the Scheme Files ==

`update_modus_schemes.py` is a Python script that regenerates all theme JSON files in place.

What the script does:

1. Downloads the palette data from https://protesilaos.com/emacs/modus-themes-colors.
2. Applies the Windows Terminal to Modus color-name mapping documented in this README.
3. Resolves semantic Modus aliases (for example, `cursor` -> `fg-main`) to concrete HEX values.
4. Rewrites each scheme JSON file in this repository with updated values while preserving the standard key order.

Run it from the repository root.
